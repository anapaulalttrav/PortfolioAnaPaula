// Projetos em Destaque

Problemas reais,
soluções mensuráveis.

Cada projeto segue a estrutura Problema → Solução → Resultado para demonstrar impacto concreto.

01 / INICIAÇÃO CIENTÍFICA

Análise de Big Data — DATASUS

Estudo analítico de uma base histórica de 10 anos (2013–2024) de dados epidemiológicos do DATASUS para inteligência em saúde pública.

Problema Dados brutos desestruturados impossibilitavam a identificação de padrões regionais de saúde.
Solução Pipeline de tratamento e estruturação de grandes volumes com R e Python, gerando visualizações no Power BI.
Resultado Mapeamento de correlações socioeconômicas e relatórios estatísticos para tomada de decisão em saúde pública.
RPythonExcelPower BI
02 / HACKATHON

API RESTful Containerizada & DevSecOps

Backend de uma API focada em escalabilidade e segurança, construída sob pressão de tempo em competição de hackathon.

Problema Necessidade de uma API segura e escalável entregue em prazo extremamente curto.
Solução Arquitetura containerizada com Docker, autenticação via tokens e isolamento de credenciais em variáveis de ambiente.
Resultado API 100% funcional com mitigação preventiva de vulnerabilidades e deploy reproduzível.
PythonPostgreSQLDockerInfoSec
03 / POO

Sistema de Conta Bancária em Java

Modelagem completa de um sistema bancário aplicando princípios sólidos de Programação Orientada a Objetos.

Problema Regras de negócio complexas exigiam código modular, reutilizável e de fácil manutenção.
Solução Arquitetura com encapsulamento, abstração e herança para modelar contas, transações e validações.
Resultado Código limpo e escalável, demonstrando domínio de padrões de projeto e boas práticas de engenharia.
JavaPOOClean Code
04 / VISÃO COMPUTACIONAL

Processamento de Imagens & Reconhecimento Facial

Algoritmo de tratamento de imagens com fundamentos para reconhecimento facial e modelos preditivos.

Problema Análise manual de imagens é lenta e propensa a erros em larga escala.
Solução Pipeline de pré-processamento e extração de features em Python no Google Colab.
Resultado Automação da análise de imagens com otimização para integração em modelos de ML.
PythonGoogle ColabOpenCV
05 / BUSINESS INTELLIGENCE

Dashboard Analítico de Consumo

Dashboard interativo no Power BI focado em comportamento de consumo para decisões estratégicas de negócio.

Problema Dados de vendas dispersos em planilhas impediam a visão holística do comportamento do cliente.
Solução Modelagem de dados com SQL e construção de dashboard com KPIs de retenção e expansão.
Resultado Transformação de dados brutos em insights acionáveis para expansão de mercado e retenção de clientes.
Power BISQLExcel
06 / IoT

Automação Residencial com IoT

Projeto integrando hardware e software para controle inteligente de dispositivos residenciais.

Problema Tarefas residenciais repetitivas sem automação geram desperdício de tempo e energia.
Solução Integração Arduino + Python para controle de sensores e atuadores via código.
Resultado Automação prática de tarefas físicas com interface programável e extensível.
ArduinoC++PythonIoT
